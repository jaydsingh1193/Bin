# Binsmith London redesign

A responsive, multi-page redesign of Binsmith London, preserving the original logo, teal/mint branding, service area and published prices.

- **Public preview:** https://jaydsingh1193.github.io/Bin/
- **Application:** `binsmith/` (Next.js static export)
- **Deployment:** GitHub Actions builds and publishes `main` to GitHub Pages.

See `binsmith/README.md` for development, content and form details.
